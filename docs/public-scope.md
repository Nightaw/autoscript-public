# 公开范围说明

## 这个仓库公开什么

- 架构设计思路
- 目录组织方式
- 通用 demo 代码
- 脱敏样例数据
- 项目亮点与面试摘要

## 这个仓库不公开什么

- 内网地址
- 账号、密码、token
- 数据库连接
- 设备清单
- 公司内部接口
- 内部 APK 或无法确认分发权限的安装包
- 原始业务脚本全集
- 真实生产环境配置
- 原始 git 历史

## 原则

如果某份代码或配置同时满足下面任意一条，就不应进入公开仓库：

- 可以直接定位到内部网络或内部服务
- 可以恢复真实生产环境
- 反映了公司业务细节而不是通用工程思路
- 其版权或使用权并不明确属于个人可公开资产
